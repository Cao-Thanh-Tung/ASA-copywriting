# 🗄️ Swipe File (Kho Tư Liệu Mẫu Tham Khảo)

## Swipe File Là Gì?
**Swipe File** là kho lưu trữ cá nhân chứa những mẫu quảng cáo, email, tiêu đề, landing page hoặc nội dung xuất sắc mà bạn bắt gặp hàng ngày. Mọi copywriter giỏi đều có một swipe file để tìm kiếm cảm hứng và phân tích cấu trúc khi "bí" ý tưởng.

---

## Cách Tổ Chức Kho Mẫu Này

Bạn có thể lưu ảnh chụp màn hình, trích dẫn hoặc phân tích vào các thư mục con:

- `headlines/`: Các tiêu đề bài viết, tiêu đề quảng cáo Facebook, Google khiến bạn phải bấm vào xem.
- `landing-pages/`: Cấu trúc các trang bán hàng có tỷ lệ chuyển đổi cao.
- `emails/`: Những email marketing mở đầu hay, kích thích đọc từ đầu tới cuối.
- `social-posts/`: Những bài viết viral, bài post kể chuyện hấp dẫn trên Facebook, LinkedIn, Threads.

---

## 🔍 Mẹo Phân Tích Một Mẫu Hay

Khi gặp một bài viết hay, hãy tự đặt câu hỏi:
1. **Hook:** Câu đầu tiên nói gì mà khiến mình dừng lại đọc?
2. **Nỗi đau / Ước muốn:** Bài viết đang nhắm vào tâm lý hay cảm xúc nào?
3. **Cấu trúc:** Tác giả sắp xếp các ý theo trình tự như thế nào?
4. **CTA:** Lời kêu gọi hành động có rõ ràng và dễ thực hiện không?
